# Tatid Timer — nedlastinger

Ferdigbygde utgaver av Tatid Timer, stoppeklokken for
[Tatid](https://tatid.favo.no) på Mac, Windows og Linux.

Dette repoet inneholder ingen kode — bare filene under **Releases**, som
publiseres automatisk når en ny versjon bygges. Last ned appen fra
**Last ned appen** i Tatid, ikke herfra: Tatid peker alltid på versjonen
som er i bruk.

Appen krever en Tatid-konto.
